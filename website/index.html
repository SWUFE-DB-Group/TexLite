核心亮点

一个工作区，覆盖从源码到成稿

用简洁的方式了解 TexLite 的核心取舍：保留熟悉的 LaTeX 环境，同时把写作、编译和协作放在同一个私有空间。

  • ↗ 核心能力

    在浏览器中编辑、编译、预览和协作，支持大纲、批注、SyncTeX 与结构化诊断。

  • ↗ 为什么选择 TexLite

    数据留在自己的服务器，编译资源不与公共实例共享；服务保持轻量，适合已经拥有 LaTeX 环境的团队。

  • ↗ 从源码到成稿

    直接使用宿主机 LaTeX，打开项目即可查看最新 PDF，需要时编译并从 PDF、源码和批注之间继续工作。

补充说明：Overleaf 在线服务在用户高峰时可能出现排队、卡顿或编译超时；Overleaf 开源 Docker 部署版本需要维护较复杂的服务栈，不包含批注等关键协作功能。

从本机开始

几条命令，拥有自己的写作空间。

TexLite 不开放公众注册。初始化时创建管理员，之后由管理员添加团队成员。

查看 npm 包↗ 阅读部署文档↗
quick-start 
$ npm install -g texlite
$ texlite init
$ texlite start

# open http://localhost:3000

另一种选择：Docker 部署

不维护本机依赖，也能快速开始。

不想维护 Node.js、TeX Live、Git 和 Harper？使用 TexLite-Docker 的已发布镜像；配置和项目数据仍保存在宿主机。

查看 Docker Hub↗ 打开 TexLite-Docker↗
docker quick-start 
$ git clone https://github.com/SWUFE-DB-Group/TexLite-Docker.git
$ cd texlite-docker
$ cp deployment.example.json deployment.json
$ ./scripts/compose.sh pull && ./scripts/compose.sh up -d

# Open http://localhost:3040
