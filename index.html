TexLite 将编辑、编译、预览和协作放进一个清爽的浏览器工作区，同时保留你熟悉的本机 LaTeX 环境。

核心亮点

一个工作区，从源码到成稿

  • ↗ 真实 LaTeX

    使用你实际的 TeX 环境、宏包、字体与工具链。

  • ↗ 私有协作

    将源码、PDF、批注与历史记录保留在你完全掌控的基础设施上。

  • ↗ 设计上不内置 AI

    TexLite 让编辑器专注写作本身。如果你需要 AI 辅助，可以使用你偏好的模型与工作流。

↔选择一个环境，逐项比较。

使用 TexLite，你的团队可以完全掌控 TeX 环境、编译资源、用户、权限以及数据。同时提供实时协作编辑、源码级批注、选区级编辑历史、SyncTeX、项目快照以及可选的 Git 备份 —— 没有外部强加的编译超时限制，设计上也坚决不内置 AI。

从本机开始

几条命令，拥有自己的写作空间。

TexLite 不开放公众注册。初始化时创建管理员，之后由管理员添加团队成员。

查看 npm 包↗ 阅读部署文档↗
quick-start 
$ npm install -g texlite
$ texlite init
$ texlite start

# open http://localhost:3000

另一种选择：Docker 部署

不维护本机依赖，也能快速开始。

不想维护 Node.js、TeX Live、Git 和 Harper？使用 TexLite-Docker 的已发布镜像；配置和项目数据仍保存在宿主机。

查看 Docker Hub↗ 打开 TexLite-Docker↗
docker quick-start 
$ git clone https://github.com/SWUFE-DB-Group/TexLite-Docker.git
$ cd texlite-docker
$ cp deployment.example.json deployment.json
$ ./scripts/compose.sh pull && ./scripts/compose.sh up -d

# Open http://localhost:3040
